
# AWS Cloud Security Assessment Project

## Project Overview

This project was completed as part of the Cloud Foundations Virtual Bootcamp Cybersecurity Analyst Capstone Project.

The objective of this assessment was to evaluate the security posture of an AWS environment, identify potential security risks, assess their impact, and provide recommendations for remediation using AWS security best practices.

## Business Problem

Organizations using cloud environments must continuously monitor and assess their security posture to prevent unauthorized access, data exposure, and security breaches.

This project addresses the challenge of identifying AWS security misconfigurations and weaknesses that could expose cloud resources to potential threats.

## Business Scenario

A personal AWS test environment was used to simulate a real-world cloud security assessment.

The environment was reviewed to identify security risks related to identity management, network security, access controls, public exposure of resources, encryption, and monitoring. Both manual review techniques and automated security scanning were used to evaluate the environment and recommend appropriate remediation measures.

## Assessment Scope

The security assessment focused on:

- Identity and Access Management (IAM)
- Multi-Factor Authentication (MFA)
- Security Groups
- Open Ports
- Publicly Accessible Resources
- Data Encryption
- Monitoring and Logging

## Assessment Methodology

The assessment was conducted through:

1. AWS environment review
2. IAM configuration assessment
3. Network security review
4. Security Group analysis
5. Data security and encryption review
6. Manual verification of security controls
7. Automated security assessment using Prowler
8. Risk analysis and prioritization
9. Remediation planning

## Tools Used

- Amazon Web Services (AWS)
- Prowler
- Draw.io

## Key Findings

- Missing Multi-Factor Authentication (MFA)
- Excessive IAM Permissions
- Open Administrative Ports
- Publicly Accessible Resources
- Missing Encryption Controls
- Security Group Misconfigurations
- Monitoring and Logging Gaps

## Recommendations

- Enable MFA for privileged accounts
- Apply the Principle of Least Privilege
- Restrict unnecessary network exposure
- Encrypt sensitive data
- Strengthen monitoring and logging
- Conduct regular security assessments
- Continuously monitor AWS security posture
